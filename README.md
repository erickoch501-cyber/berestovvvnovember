# ECommerceCsvImport

Модуль импорта товаров в электронный магазин из CSV-файлов с хранением данных в коллекциях в памяти.
Производственная практика ПП.02.01 (ПМ.02 Осуществление интеграции программных модулей), специальность 09.02.07 Информационные системы и программирование.
Вариант 1 "Электроника".

## Описание задания

ASP.NET Core MVC-приложение на C#, которое:

- загружает CSV-файл с данными о товарах и читает его построчно;
- преобразует строки в объекты Product и проверяет корректность данных;
- добавляет корректные товары в коллекцию в памяти (база данных не используется);
- показывает результат импорта: всего строк, успешно импортировано, количество ошибок, список ошибок с номерами строк;
- показывает список загруженных товаров.

## Структура проекта

- `src/ECommerceCsvImport` - веб-приложение (Controllers, Models, Services, Views, wwwroot/csv)
- `tests/ECommerceCsvImport.Tests` - unit-тесты xUnit и тестовые CSV-файлы (testdata)

## Формат CSV

Первая строка - заголовки:

`sku,name,description,price,currency,category_name,stock,image_url,is_active,brand,warranty_months,model_number`

| Поле | Правило |
|------|---------|
| sku | обязательно, уникальное |
| name | обязательно |
| price | число больше 0 |
| currency | если пусто, то RUB |
| category_name | если пусто, то "Без категории" |
| stock | целое число, не меньше 0 |
| is_active | true, false, 1, 0 |
| brand | обязательно |
| warranty_months | целое число от 0 до 60 |
| model_number | может быть пустым |

Дубликаты SKU пропускаются, для них добавляется ошибка "Артикул товара уже существует".

## Запуск

```
dotnet run --project src/ECommerceCsvImport
```

На странице "Импорт товаров" указать путь `/csv/sample_products.csv` и нажать "Импортировать товары".
